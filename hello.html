How to read this

Why a table at all

The router only has one public IP, so it tells sessions apart by port. The table is the only place that link between a private host and its public port is recorded — lose it, and a reply has nowhere to go.

This is PAT / NAPT

Two hosts sharing one public IP via distinct ports is Port Address Translation — the form of NAT almost every home and office router runs.

What actually changes

Only the IP and port fields are rewritten. The payload — the HTTP request itself — passes through untouched.

Why inbound is hard

A host on the internet can't start a connection to 192.168.1.10 — there's no table row yet to translate through. Port forwarding exists to solve exactly this.
